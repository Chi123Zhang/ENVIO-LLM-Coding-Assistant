# Completion pilot: evidence before imputation

Open **ORCCA Workflow → H3 study preparation → 3 · Evidence and completion → Completion evaluation · run a small pilot**. Load an original Tracker and dictionary in private mode, or load the synthetic project for a public recording. Click **Run current-input completion pilot**, inspect the source memory, then download the separate review forms.

## Scope and methods

The first protocol screens only OEND and MOUD slot-1 implementation-start fields. It reads exact version-specific dictionary choices and evaluates only supported flat binary equality conditions joined by AND or OR. Unknown dependencies, mixed operators and unsupported expressions remain unresolved. A false display condition is a candidate structural skip, not a confirmed missing or erroneous response. Empty cells must not be recoded as No.

Applicable observed binary cells are selected deterministically into a maximum 24-case masking pilot. Counties in sorted order are assigned alternately to development and heldout pilot groups; those groups never share a county. Selection interleaves county, menu, version and recorded class. This split is frozen before outputs, but because the outputs are reviewed during development it is not a final confirmatory test set. Report class imbalance and small independent county count.

Two methods run without access to target values:

- **Rules only:** exact version/field definition lookup; abstain without independent state evidence.
- **BM25 source memory:** actual ENVIO BM25 retrieval over frozen dictionary excerpts, followed by the same state-evidence requirement. A dictionary definition cannot establish an actual county-month state.

No whole Tracker row, adjacent snapshot, derived table, human answer, model output or review decision enters retrieval memory. Shared dictionary definitions contain no county outcome answers. The memory is a source store tied to the current input fingerprint, rebuilt for changed inputs. It is not an LSTM, model fine-tuning, reinforcement learning or automatic learning from approvals. Input replacement/removal clears the pilot. External generation is disabled. Hybrid and No-RAG/RAG LLM comparisons are not run by this pilot.

This is deliberately a **feasibility experiment**: the admitted sources currently describe field semantics, not independent county-time states. Numerical predictions therefore remain unknown. That outcome must not be marketed as successful value recovery, a comparison with a validated imputation model, or a RAG accuracy gain. Independent assertions need provenance review and a new frozen protocol before they can be admitted. Do not synthesize state assertions by copying masked cells into a supposed evidence document.

## Review materials and measurement

The coordinator ZIP contains two identical independent A forms with blank human answers and no system judgments; B contains system comparisons, source retrieval IDs and memory settings. Recorded references are separate. Additional unresolved/skip cases are included in the forms up to 28 cases when available. An observed masked reference is an original recorded value, not a validated human label. Blanks with unresolved applicability remain unresolved; they are not all unreported.

Give each reviewer only their A form and authorized original sources. Allowed answers are 0, 1 or unknown, with answerability, missingness type, evidence, reason, annotator and measured active seconds. Lock both independent submissions before sharing B or reconciling disagreements with a third reviewer/documented consensus. Do not use software wall-clock runtime as human review time. No independent labels or time-saving measurements are bundled.

Metrics distinguish correct/incorrect/unknown per masked case and accuracy among proposed values (undefined when there are no proposals). Human correctness, evidence support, agreement and review time remain unmeasured until real reviews arrive. Masking observed values does not simulate the mechanism of naturally missing data. No H3 mediation model is estimated.
